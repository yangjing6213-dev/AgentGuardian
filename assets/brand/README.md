# AgentGuardian Brand Assets

## Trust Frame

四个开放角表示扫描范围、证据边界和透明审计；`AG` 是品牌核心识别。不得把开放角闭合成盾牌或锁，也不要用 LOGO 单独表达风险状态。

颜色：

- Obsidian: `#0F1215`
- Cloud: `#F4F6F7`
- Trust: `#15A36D`
- Signal: `#2A8CCB`
- Warning: `#D49A32`
- Critical: `#C64A43`

资产：

- `agentguardian-mark.svg`：透明浅色背景标志。
- `agentguardian-mark-dark.svg`：深色背景标志。
- `agentguardian-wordmark.svg`：桌面与报告页眉组合标志。
- `agentguardian-cover.svg`：1280 × 640 GitHub 初代封面，数据明确为 `SYNTHETIC DEMO`。
- PNG 文件是对应的发布预览，不替代 SVG 源文件。

16px 以下只使用 mark，不使用 wordmark。浅色背景上的关键笔画和文字使用 Obsidian；深色背景上的 Trust 可承载文字和关键图形。Warning、Critical 和 Signal 只作状态或辅助信号，关键状态同时显示文字。
