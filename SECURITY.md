# Security Policy

## Scope

AgentGuardian is currently a Windows 11 x64 preview for personal,
non-regulated configuration data. It is not production-safe and must not be
used with highly sensitive real data.

## Reporting a vulnerability

Do not include credentials, private URLs, customer data, browser databases,
clipboard contents, or other sensitive material in a public issue. Use the
repository's private vulnerability-reporting channel when it is enabled. If
that channel is unavailable, open a minimal public issue that contains no
exploit details and ask the maintainers for a private contact path.

Please include the affected version or commit, operating system, a minimal
reproduction using synthetic data, and the impact. Redact logs and remove
local paths before sharing them.

## Disclosure boundary

Reports are triaged by the project owner. A fix, release, or severity label is
not promised by this document. Local tests and a preview artifact do not prove
production safety, complete coverage, or absence of vulnerabilities.
