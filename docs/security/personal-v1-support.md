## Ordinary support

- ordinary support: live
- URL: https://github.com/yangjing6213-dev/AgentGuardian/issues

Use GitHub Issues for ordinary product questions and non-sensitive bug reports. Include only redacted information. Do not include user content, credentials, full local paths, private reports, or other sensitive evidence.

## Sensitive vulnerabilities

GitHub Private Vulnerability Reporting is currently disabled. The repository security advisory submission page must not be described as live.

No private vulnerability intake is currently available. Do not submit sensitive vulnerability details in a public Issue. Preserve the minimum local evidence and wait for an authorized private channel to be published.

- operations/security channel gate: pending

No support email is asserted. Release remains `NO-GO` until the operations gate records a verified private security channel and support procedure.
