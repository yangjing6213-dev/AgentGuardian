# AgentGuardian Bilingual UI, Audit Repair, and Local Installer

## Original Goal
Optimize the AgentGuardian desktop application: bilingual installer and switchable Chinese/English runtime UI; improve the interface with Microsoft YaHei; create a shield and ENHE-inspired desktop icon; add a polished author page using the supplied image and details; diagnose and fix the audit failure and consent checkbox behavior; rebuild, reinstall the local application, and verify it.

## Task Contract
- Requirements: preserve existing audit/security boundaries; local, read-only audit; no provider API calls; Chinese and English installation/runtime surfaces; runtime language switching; an About the Author view with the provided image and information; generated app icon; retain the user's selected scan scope after starting; show useful safe error information; rebuild and locally verify.
- Constraints: the provided project directory has no `.git`; do not publish, push, sign, or change the remote release; preserve protected state and user configuration during reinstall; the current release is explicitly unsigned and limited to personal non-regulated configuration data.
- Acceptance Criteria:
  1. Every primary runtime page and scan/action state can be switched between Chinese and English, and the choice persists after restart.
  2. The setup wizard supports English and Simplified Chinese and translates the preview disclosures without removing them.
  3. The generated icon is embedded in the executable and installer and combines a shield with the supplied ENHE brand direction.
  4. The author page presents the supplied poster and all user-provided contact details clearly.
  5. A successful audit leaves the selected scope consent visible; changing scope revokes consent.
  6. A reproduced audit failure exposes a safe actionable reason; no secrets, file contents, or private paths are logged or displayed.
  7. A fresh local installer is built, the existing AgentGuardian installation is upgraded/reinstalled without purging protected state, and a synthetic-data audit succeeds in the installed application.
- Deliverables: source changes, generated icon asset, local installer/executable artifacts, updated verification evidence, and this task record.
- Non-goals: publishing a release, pushing to GitHub, signing the installer, uploading audit data, or modifying unrelated system/application data.
- Risks: build requires a compatible Windows Python/PySide6 and Inno Setup toolchain; existing uninstaller behavior may remove the installed AgentGuardian Codex integration, so its exact targets and reinstall behavior must be checked before running it; the public preview's unsigned warning will remain unless a trusted code-signing certificate is available.
- Testing Strategy: targeted audit/UI regression checks; installer source/build checks; full focused test suite; packaged executable smoke check; inspect install ownership and user-data behavior; run an audit only against a newly created synthetic folder; inspect final output and filesystem status.
